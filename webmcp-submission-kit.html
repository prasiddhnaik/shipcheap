Ready-to-paste description

ShipCheap helps beginners choose where to host a backend without getting trapped by card requirements, confusing free tiers, or surprise usage bills. WebMCP is a strong fit because hosting decisions are naturally multi-step and constraint-heavy. A person can describe their runtime, database, region, budget, card access, uptime needs, and risk tolerance in plain language. Their agent calls ShipCheap's structured recommendation tool, then opens a recommended provider in the visible comparison and configures a 1,000-month billing-risk simulation for the person to review. The human keeps the final decision; the agent handles the repetitive filtering and configuration. This is better than UI-only automation because the agent does not need to guess which controls to click or scrape result cards. ShipCheap exposes three imperative tools through document.modelContext.registerTool: recommend_backend_hosts, open_backend_host_comparison, and preview_billing_risk. Each tool has a constrained JSON Schema, validates inputs again during execution, and returns concise structured results. Navigation tools update the same visible pages the person uses. The WebMCP extension is progressive enhancement and was added to the pre-existing ShipCheap app during the challenge submission period. The site still works normally without WebMCP. None of the tools can deploy infrastructure, attach billing details, spend money, or alter a hosting account.

Testing instructions

  1. Open the live URL in ChatGPT's in-app browser, or Chrome 149+ with chrome://flags/#enable-webmcp-testing enabled.
  2. Ask: “Recommend a free, no-card host in Asia for an always-on Node backend with Postgres and low billing risk.”
  3. Ask the agent to open the top hosted-platform recommendation for comparison.
  4. Ask it to preview billing risk for 500 monthly users, 35 requests per user, a small database, budget alerts, and a $25 budget.
  5. Confirm the browser opens the configured risk simulator and the visible provider and usage fields match the request.
